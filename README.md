# Kenku FM (Speakeasy edition)

[Kenku FM](https://github.com/owlbear-rodeo/kenku-fm) with a Speakeasy output: play music, sound effects and any
website's audio into Speakeasy voice channels (and Discord).

- **Install:** download `Kenku-FM-Speakeasy-Setup.exe` from the [latest release](../../releases/latest), or install
  it from [OneStop](https://github.com/JaggerBean/OneStop-releases).
- **Use:** open the Speakeasy output, sign in with your Speakeasy account and pick a voice channel.
- **Updates:** installed copies update themselves from this repo's latest release.

(`kenku-fm-speakeasy-<version>-source.tar.gz`).
